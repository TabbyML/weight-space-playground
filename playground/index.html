Weight-space programming

Breaking reasoning loops by editing model weights.

Qwen3.5-0.8B can get stuck rechecking the same reasoning, using up its token budget before reaching an answer. In Sparks of Weight-Space Programming, an AI agent reduced this behavior by directly editing a small set of its weights - without fine-tuning.

Explore what changed: watch the original and edited models answer the same questions, inspect the weight changes, then look at neuron activity during those runs.

The problem: repeated reasoning

In the original experiment, Qwen3.5-0.8B often repeated its reasoning until it hit the token limit before reaching an answer. These figures come from the original experiment’s published evaluation.

The intervention: a small weight edit

It subtracts one direction from 64 neurons' output weights (ffn_down) in layers 15 and 19 - 131,072 of ~800M weights.

The result: fewer capped runs

The original experiment reported fewer capped runs and higher MATH-500 accuracy. Some runs still reached the token limit.

A familiar experimental loop

Start with a few examples of unwanted behavior, propose an edit, and test whether it helps. Then check other examples for regressions. People working with prompts or fine-tuning will recognize the pattern. An AI agent makes this loop practical at the weight level: it can inspect tensors, write editing code, run evaluations, and use the results to choose the next experiment.

Key neurons during inference loading…

The 64 edited neurons of layers 15 and 19, token by token, on the recorded runs. Synced to the replay above: hover to peek, drag to scrub.

  1. Loops light them upWhen the original model starts repeating itself, these neurons fire harder: the push the edit adds is about 2-4× bigger inside loops than in the rest of the same run.
  2. The edit pushes backThat push points against what the neurons were writing, so the harder they fire, the harder the edit steers away from the loop.
  3. Layer 19 calms downRun the edited weights over the same looping text (dashed line) and layer 19 is about half as active (≈ 2.1 compared with ≈ 4.0).
  4. The loop gets wobblyIts next tokens stop being a sure thing: 15.9% of loop tokens fall below 90% probability, against 0.4% for the original.
